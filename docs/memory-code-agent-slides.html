collectSurfacedMemories()

为什么不会反复注入同一条记忆

  • 扫描当前 messages 中已有的 relevant_memories
  • 选择前排除已经出现过的 path
  • readFileState 再排除模型主动读过的文件
  • 同时累计正文 bytes，执行 60KB throttle

Takeaways

记住三件事

01

Instructions、Auto、Agent、Session Memory 同属持久上下文，但不是同一套机制。

02

规则分层加载，长期记忆按需召回，专家经验隔离，会话状态滚动摘要。

03

Session Memory 预计算 compact 摘要；长期文件仍可重新加载或召回。

收束到三个可以复述的句子。然后预告下一次：上下文工作台真的放不下时，系统删了什么、总结了什么、重建了什么？
